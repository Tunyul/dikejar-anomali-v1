# Visual Style Guide - Anomaly Rush Web

Dokumen ini berisi panduan visual (UI/UX) untuk website **Anomaly Rush**. Website ini **HARUS** mencerminkan estetika game aslinya secara akurat. Jangan gunakan desain corporate/minimalis standar.

## 🎨 Core Design Philosophy
- **Playful & Energetic**: Gunakan warna cerah, saturasi tinggi.
- **Cartoonish 3D**: Tombol dan panel memiliki kedalaman (depth/shadow), outline tebal, dan efek glossy.
- **Mobile-First Layout**: Desain tombol besar dan mudah ditekan (touch-friendly), mengingat game ini adalah mobile game.

---

## 🖼️ Referensi Aset Game (Wajib Tiru)

### 1. Main Menu Style
*Lihat referensi: Screenshot Main Menu*
- **Background**: Langit biru cerah dengan awan putih bulat (cartoon style) dan bukit hijau berlayer.
- **Logo**: Logo "Anomaly Rush" besar di tengah dengan efek ledakan/komik.
- **Tombol Utama**:
  - Bentuk: Rounded rectangle (sangat tumpul).
  - Warna: Hijau (#TBD), Biru (#TBD), Kuning (#TBD).
  - Style: Glossy (kilap di atas), ada shadow tebal di bagian bawah untuk efek 3D.
  - Icon: Icon putih sederhana di tengah tombol (Keranjang, Play, Gear).

### 2. Panel UI & Popups
*Lihat referensi: Panel Misi & Shop*
- **Container**:
  - Warna: Hijau Neon cerah / Transparan gelap.
  - Border: Outline tebal (biasanya hijau tua atau putih).
  - Header: Tab navigasi di bagian atas (Harian, Mingguan, dll) dengan style tombol pil.
- **List Item**:
  - Background item: Hijau lebih gelap/transparan.
  - Progress Bar: Flat, warna cerah (kuning/hijau muda).
  - Tombol Action (Klaim/Beli): Kotak dengan icon gift/cart.

### 3. Loading Screen
*Lihat referensi: Loading Screen*
- **Background**: Hitam solid (atau transisi ke scene game).
- **Elemen**: Karakter utama berlari dikejar Spike/Anomaly.
- **Teks**: "Memuat X%" di bagian bawah tengah.
- **Penggunaan di Web**: Gunakan ini sebagai *Preloader* atau transisi antar halaman berat.

## typography & Colors

### Font
- **Primary Font**: Gunakan font yang sama dengan game (kemungkinan **Fredoka One**, **Nunito Rounded**, atau sejenisnya).
- **Karakteristik**: Rounded, tebal, friendly.

### Color Palette (Estimasi dari Screenshot)
- **Primary Green**: Hijau rumput cerah (Background bukit/tombol Play).
- **Neon Green**: Panel background (Misi).
- **Sky Blue**: Langit background.
- **Gold/Yellow**: UI Koin, Progress Bar, Tombol penting.
- **Purple**: Tombol Settings, Aksen border.
- **Red/White**: Bendera bahasa.
